# Web API Test Lab

Web tabanlı, hafif ve pratik bir API test aracı (Postman benzeri). GET, POST, PUT, DELETE isteklerini test etmek, durum kodlarını incelemek ve JSON yanıtlarını görüntülemek amacıyla Node.js & Express altyapısıyla geliştirilmiştir.

## Geliştiriciler & İş Bölümü
- **Wesley (@07wess):** Arayüz tasarımı, bileşen düzeni ve HTML/CSS
- **Selin (@L1LLEY):** Backend API, veri yönetimi ve logic

## Kurulum ve Çalıştırma

```bash
# Bağımlılıkları yükleyin
npm install

# Sunucuyu başlatın
npm start
```

Sunucu çalıştığında tarayıcınızdan `http://localhost:3000` adresine giderek arayüzü doğrudan kullanabilirsiniz.
